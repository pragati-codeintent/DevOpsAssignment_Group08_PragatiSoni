## 📖 Introduction

**Kubernetes (K8s)** is an open-source container orchestration platform originally developed by **Google** and is now maintained by the **Cloud Native Computing Foundation (CNCF)**.

It automates the deployment, scaling, and management of containerized applications. Kubernetes helps developers efficiently run applications across multiple servers while ensuring high availability, scalability, and reliability.

## 🔄 Kubernetes Workflow

1. Develop the Application
2. Create a Docker Image
3. Push the Image to a Container Registry
4. Deploy the Application to Kubernetes
5. Kubernetes Creates and Manages Pods
6. Expose the Application using Services
7. Scale the Application Automatically
8. Monitor and Maintain the Cluster
