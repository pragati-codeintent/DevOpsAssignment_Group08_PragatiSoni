## How to Check the Uploaded Files

To check all files that are officially part of the project:

1. Open this GitHub repository.
2. Select the **`main`** branch from the branch selector.
3. The files and folders displayed on the repository homepage are the files currently present in `main`.
4. Open a folder to see the files inside it.
5. Click a PDF file to open or view it.
6. Click **README.md** to read the project documentation.

### Checking a Contributor's Work

Individual contributors may work on separate branches.

To check a contributor's work:

1. Open **Branches**.
2. Select the contributor's branch.
3. Check the files and commits on that branch.
4. A Pull Request shows the changes proposed for `main`.
5. Open **Files changed** in the Pull Request to see exactly what that contributor added or modified.

## Branching Workflow

The project uses branches so that contributors can work independently without directly changing the `main` branch.

```text
main
 │
 ├── Contributor Branch
 │      │
 │      ├── Add files
 │      ├── Commit changes
 │      └── Push changes
 │
 └── Pull Request
        │
        └── Review → Merge → main
```

Each contributor should:

1. Create or use their own branch.
2. Add their assigned work.
3. Commit the changes.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. Get the changes reviewed.
7. Merge the Pull Request into `main`.

       ↓
