# JobTrack

JobTrack is a full-stack job application tracking web application that helps users manage and organize their job search process in one place.

## Features

- User registration and login
- JWT-based authentication
- Add, update and delete job applications
- Track application status
- Kanban-style job tracking board
- Job application dashboard
- Resume upload and management
- Calendar for application tracking
- Analytics and application statistics
- User profile management

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer
